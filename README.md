# netw0rking

Network automation and lab projects: data center fabrics, backbone routing, and NetBox-driven automation.

- EVPN/VXLAN, IS-IS, BGP, SR-MPLS
- NetBox as source of truth, Python (Netmiko, Nornir, NAPALM), Jinja2
- containerlab, Docker, Kubernetes (K3s), GitHub Actions

## Projects

- [netbox-ztp-lab](https://github.com/netw0rking/netbox-ztp-lab): NetBox-driven ZTP for a Clos fabric and a 10-site SR-MPLS backbone
- [network-automation](https://github.com/netw0rking/network-automation): scripts and config templates for Cisco, Juniper, and Arista
